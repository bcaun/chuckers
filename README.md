# Шашки — Telegram Mini App

Русские шашки в виде мини-приложения Telegram. Чистый HTML/CSS/JS без сборки.

## Возможности
- Полные правила русских шашек: обязательное взятие, бой назад, «дальнобойные» дамки,
  превращение в дамку посреди взятия, запрет «турецкого удара».
- Игра с ботом (лёгкий / средний / сложный), выбор цвета.
- Игра вдвоём на одном устройстве.
- Отмена хода, подсветка ходов и обязательных взятий, анимация многоходовых взятий.
- Ничья: троекратное повторение позиции или 15 ходов дамками без взятий.
- Интеграция с Telegram: тема и цвета клиента, виброотклик (HapticFeedback),
  системная кнопка «Назад», статистика побед в CloudStorage (синхронизируется между устройствами).

## Структура
```
webapp/          статика мини-аппа
  index.html
  styles.css
  engine.js      правила и генерация ходов
  ai.js          бот (alpha-beta + итеративное углубление)
  app.js         интерфейс и Telegram WebApp API
bot/bot.js       бот, который открывает мини-апп (Node 18+, без зависимостей)
```

## Локальный запуск
```bash
cd webapp && python3 -m http.server 8080
# открыть http://localhost:8080 — работает и в обычном браузере
```

## Запуск в Telegram
1. **Хостинг.** Мини-апп нужен по HTTPS. Проще всего — GitHub Pages
   (выложить содержимое `webapp/`), Netlify, Vercel или Cloudflare Pages.
   Для тестов с локальной машины подойдёт `ngrok http 8080`.
2. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot` → получить токен.
3. **Мини-апп.** В BotFather: `/newapp` → выбрать бота → указать URL из шага 1.
   Приложение откроется по ссылке `t.me/<бот>/<short_name>`.
4. **Кнопка в боте** (по желанию):
   ```bash
   cd bot
   BOT_TOKEN=123:ABC WEBAPP_URL=https://you.github.io/checkers/ node bot.js
   ```
   Бот ответит на `/start` кнопкой «Играть» и поставит её в меню чата.
   Вместо скрипта кнопку меню можно задать в BotFather: `/mybots` → Bot Settings → Menu Button.

## Что можно добавить дальше
- Онлайн-игру с другом: нужен сервер (WebSocket) и приглашение через `switchInlineQuery`
  или ссылку `t.me/<бот>/<app>?startapp=<id_партии>`; пользователя проверять по `initData`.
- Рейтинг и таблицу лидеров.
- Перенос бота в Web Worker, чтобы сложный уровень не подтормаживал анимацию.
