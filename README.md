# Шашки — Telegram Mini App

Русские шашки в Telegram: бот с 5 уровнями, игра с другом по приглашению, статистика, покупки за Telegram Stars.

- 📖 [Подробное описание игры](docs/GAME.md)
- 🚀 [Развёртывание на своём VPS](docs/DEPLOY.md)

## Возможности
- **Правила русских шашек**: обязательное взятие, бой назад, «дальнобойные» дамки,
  превращение в дамку посреди взятия, запрет «турецкого удара», ничья по повтору позиции и 15 ходам дамками.
- **Бот, 5 уровней** (Новичок → Гроссмейстер). Открыт только 1-й уровень; 5 побед на максимальном
  открытом уровне открывают следующий. Поиск хода идёт в Web Worker — интерфейс не тормозит.
- **Игра с другом**: приглашение через «Поделиться» в Telegram, сервер проверяет каждый ход,
  предложение ничьей, сдача, реванш (цвета меняются). Отключившемуся даётся 2 минуты вернуться.
- **Вдвоём на одном телефоне.**
- **Статистика**: партии, победы, серии, разбивка по уровням бота и играм с друзьями, последние 10 партий.
- **Аватар**: 24 эмодзи, загрузка своего фото (обрезается до 256×256 на телефоне) или фото из Telegram.
- **Покупки за звёзды (по 100 ⭐)**:
  - следующий уровень бота — только на один уровень вперёд; после купленного уровня
    следующий нужно выиграть (два уровня подряд купить нельзя);
  - отмена хода в игре с ботом — навсегда;
  - 20 цветов шашек для себя и соперника — навсегда.

## Как устроено
```
webapp/              клиент (статика, без сборки)
  index.html, styles.css
  app.js             экраны, доска, режимы игры
  api.js             REST + WebSocket к серверу
  engine.js          правила (общий с сервером)
  shared.js          цвета, уровни, товары (общий с сервером)
  ai.js, ai-worker.js бот
server/              Node.js: API, онлайн-партии, бот, платежи
  index.js           HTTP + WebSocket, раздаёт webapp/
  auth.js            проверка подписи initData
  users.js           профили, статистика, прогресс уровней
  shop.js            товары и правила покупки
  telegram.js        Bot API: /start, счета XTR, pre_checkout, successful_payment, возвраты
  botgames.js        приём итогов партий с ботом (партия переигрывается и проверяется)
  rooms.js           комнаты игры с другом
  db.js              хранилище (JSON-файл в server/data/)
```

Защита от накруток: пользователь определяется по подписанному Telegram `initData`; прогресс, покупки и
статистика хранятся только на сервере; победа над ботом засчитывается, только если присланная
запись партии проходит проверку по правилам и заканчивается победой. Выход из начатой партии с ботом — поражение.

## Локальный запуск (без Telegram)
```bash
cd server && npm install
npm run dev            # DEV=1: вход без Telegram, покупки выдаются бесплатно
# http://localhost:8080
# второй игрок для проверки игры с другом — другая вкладка с ?dev_user=2
```

## Ограничения и что дальше
- Хранилище — JSON-файл: хватит на тысячи игроков; для большего — заменить `db.js` на SQLite/Postgres.
- Онлайн-комнаты живут в памяти: перезапуск сервера обрывает идущие партии.
- Ходы бота считаются на телефоне, поэтому теоретически можно подделать партию целиком
  (сыграв за обе стороны). Полностью закрыть это можно, только считая ходы бота на сервере.
- Возврат звёзд вручную: `refundStarPayment` (charge id хранится в `data.payments`).
